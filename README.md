# Lyceum N21

Інформаційний портал ліцею №21 міста Житомира для учнів, батьків і вчителів.

На сайті зібрано історію ліцею, новини та оголошення, відомості про педагогів, контакти й корисні матеріали про навчання та шкільне життя.

## Можливості порталу

- Розклад уроків для 1–9 класів і розклад дзвінків із перервами.
- Особистий кабінет учня з оцінками, відгуками та домашніми завданнями.
- Журнал учителя для оцінювання й публікації домашніх завдань.
- Новини ліцею у прокручуваному списку.
- Історія закладу, педагогічний склад і класні керівники.
- Інформація про вступ, харчування, безпеку та підтримку учнів.
- Фотографії ліцею, адреса, телефон і електронна пошта.

Портал адаптований до комп’ютерів і телефонів, має світлу й темну теми та циклічний відеофон.
