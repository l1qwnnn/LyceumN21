# Lyceum N21

Інформаційний портал Житомирського міського ліцею №21: навігатор за інформацією, біографія закладу,
педагогічний склад, розклад дзвінків і тижневий план, меню їдальні, електронний щоденник з балами
1–12 та панель вчителя, яка ці бали виставляє.

## Два способи отримати сайт

Ця папка є єдиним місцем, де правиться код. З неї збирається автономний файл
`../lyceum-n21.html`, у якому стилі, скрипти й зображення вбудовані всередину сторінки:

```
node lyceum-n21/bundle.js
```

Файл `lyceum-n21.html` не робить зовнішніх запитів і відкривається подвійним кліком з будь-якої
теки. У ньому немає маніфеста PWA, сервіс-воркера та `404.html`, бо для них потрібні окремі файли;
решта функціоналу збігається. Правити `lyceum-n21.html` вручну не потрібно, його перевипускають.

## Запуск

Сайт не потребує збірки та зовнішніх залежностей.

Варіант 1, найпростіший: відкрийте `index.html` подвійним кліком. Усі розділи доступні через
хеш-маршрути (`#/teachers`, `#/diary`), тому файловий протокол працює так само, як і хостинг.

Варіант 2, з повним функціоналом PWA (сервіс-воркер, офлайн-кеш, встановлення на пристрій):

```
npx serve lyceum-n21
# або
python -m http.server 8000
```

Сервіс-воркер реєструється лише за `http:` або `https:`, у `file:` він просто не активується.

## Структура

| Файл | Що містить |
| --- | --- |
| `index.html` | розмітка, SVG-спрайт іконок, мета-теги, скрипт теми до першого кадру |
| `style.css` | усі стилі, змінні теми (темна й світла), кольори балів |
| `data.js` | контент порталу: директорі, історія, новини, події, вчителі, розклад, предмети, перелік учнів, меню |
| `app.js` | маршрутизація, рендер сторінок, автентифікація, щоденник, панель вчителя, таймер дзвінків |
| `manifest.webmanifest` | PWA-маніфест для встановлення |
| `sw.js` | сервіс-воркер: офлайн-кеш і резервна сторінка |
| `404.html` | резервна сторінка для хостингу (GitHub Pages та подібні) |
| `assets/` | логотип і превʼю для соціальних мереж |
| `bundle.js` | збирає з усіх файлів один автономний `../lyceum-n21.html` |

Дані й логіка розділені: щоб оновити розклад, вчителів чи меню, достатньо відредагувати `data.js`.

## Ролі та вхід

Реєстрація збирає ПІБ, номер телефону та пароль; за замовчуванням створюється учнівський профіль.
Клас на цьому кроці не вибирають: його вказують у розділі «Щоденник», він зберігається у профілі.

- **Учень** бачить власний щоденник: бали з кожного предмета, середній бал, найкращий предмет,
  домашні завдання.
- **Вчитель** на формі реєстрації натискає «Реєстрація для педагога ліцею» і вводить код доступу
  (`TEACHER_CODE` у `data.js`, типово `12345`). Конкретного вчителя зі списку не обирають:
  ПІБ і класи беруться з профілю. У панелі спочатку обираєте клас, далі учня зі списку класу,
  вписуєте бали та натискаєте «Зберегти оцінку». Саме ці бали учень бачить у щоденнику.

Паролі не зберігаються у відкритому вигляді: у `localStorage` потрапляє подвійне хешування
телефону й пароля. Реалізація клієнтська, без сервера.

## Перерви

Окремого списку перерв у даних немає: `breakAfter()` у `app.js` рахує їх з графіка дзвінків
`BELL` у `data.js`. Змінили дзвінок перерва зміниться сама. У розділі «Розклад» між уроками
стоїть лише кількість хвилин.

## Що варто заповнити своїми даними

Справжні дані ліцею: перелік директорів з 1962 року, роки та етапи історії, прізвища та предмети
педагогічного складу, адресні й реквізитні дані, розклад дзвінків.

Умовні, їх править адміністратор порталу: номери телефонів окремих вчителів, меню та ціни,
новини й дати подій, перелік учнів `PUPILS` у `data.js`. Бали щоденника порожні до першого
запису вчителя.

## Обмеження

- Автентифікація клієнтська: справжній сервер (Firebase, Supabase) не підʼєднано, тож ролі
  не захищені від досвідченого користувача. Для бойового використання потрібен бекенд.
- Бали зберігаються в `localStorage` конкретного браузера й не синхронізуються між пристроями.
- Сторінка тільки українською; англійської версії немає.
- Світлини та галерея замінені на іконки й текстові картки, щоб сайт не робив зовнішніх запитів.
