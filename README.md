# Lyceum N21

Портал ліцею, розклад для 1–9 класів, електронний щоденник і журнал учителя. Публічні сторінки можна відкрити через `index.html`. Для спільних облікових записів, оцінок, завдань і запрошень потрібен сервер.

## Запуск сервера

Потрібен Node.js 24 або новіший. Після `npm install` для першого запуску в PowerShell задайте номер адміністратора й пароль від 12 символів із літерами та цифрами.

```powershell
$env:LYCEUM_ADMIN_PHONE = '+380XXXXXXXXX'
$env:LYCEUM_ADMIN_PASSWORD = '<ваш пароль>'
node server.js
```

Відкрийте [портал](http://127.0.0.1:8000). Сервер створює першого адміністратора у SQLite під час запуску. Після цього пароль змінюється в профілі. За замовчуванням база зберігається в `lyceum.sqlite`. Змінна `LYCEUM_DB` задає інший шлях.

На Vercel статичні сторінки публікуються з кореня проєкту, а `api/index.js` обробляє запити кабінету. Підключіть Neon до проєкту Vercel і надайте змінну `POSTGRES_URL` для Production та Preview. База створює потрібні таблиці під час першого звернення до API. Для першого адміністратора задайте `LYCEUM_ADMIN_PHONE` і `LYCEUM_ADMIN_PASSWORD` як секретні змінні середовища Vercel. На Vercel SQLite не використовується: записи мають зберігатися в Neon. Після зміни змінних середовища виконайте повторне розгортання.

Для іншого Node-хостингу зі сталим диском і HTTPS можна використовувати SQLite. Задайте `LYCEUM_ORIGIN` як повну публічну адресу без шляху, наприклад `https://school.example`. Сервер слухає `127.0.0.1:8000`. На хостингу за потреби задайте `HOST` та `PORT`. Вебсторінки й API обслуговує той самий сервер.

Автономний файл публічних сторінок можна зібрати командою `node bundle.js lyceum-n21.html`. Статичний хостинг також підтримує публічні матеріали. Попередні профілі й оцінки з локального сховища браузера залишаються там. Для нового кабінету зареєструйтеся повторно.

## Відеофон, розклад і новини

- У `assets/background.mp4` змонтовано прямий і зворотний хід відео. Браузер відтворює його без звуку з повтором.
- Офіційний графік дзвінків на 2026/27 взято зі [сторінки ліцею](https://21.lic.zhitomir.ua/rezhim-roboti-zakladu-2/). Поки немає підтвердженого поурочного розкладу класу, портал показує позначений зразок за типовими програмами МОН.
- У `data.js` змінна `CLASS_SCHEDULES` приймає п’ять масивів із назвами уроків від понеділка до п’ятниці. Наприклад, ключем може бути `'7-В'`. Імена класних керівників за класами містяться в `CLASS_CURATORS`.
- Новини завантажуються з офіційної стрічки. Публікації давніші за календарний місяць автоматично зникають.
- Учень обирає клас під час реєстрації. Згодом змінити його можна через «Адміністрування» за номером телефону. Журнал 5–9 класів підтримує бали 1–12, для 1–2 класів доступні текстові відгуки, для 3–4 також рівні.

Код для реєстрації вчителя видає адміністратор у вебкабінеті. Він діє 24 години та прив’язаний до номера телефону.
