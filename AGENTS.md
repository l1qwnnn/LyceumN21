# Правила работы с проектом

Запрещено выполнять `git commit`, `git push` и изменять репозиторий через GitHub API без отдельного прямого разрешения пользователя на конкретное действие.

Обычная просьба изменить сайт, исправить ошибку или обновить файлы не является разрешением создать коммит, отправить изменения или опубликовать сайт.

По умолчанию изменения выполняются только в локальных файлах. Нельзя обходить этот запрет через временную копию репозитория, другой инструмент, браузер, скрипт или субагента. Разрешение на предыдущую публикацию не распространяется на будущие изменения.
